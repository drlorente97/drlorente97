## Hola, soy Angel 👋

Soy Angel Pérez Lorente (_drlorente97_), fundador de **[DeSoluTec](https://www.desolutec.com)** (Desarrollo y Soluciones Tecnológicas S.A.S.), una startup colombiana que desarrolla apps web y para iOS.

### Lo que estamos construyendo

**Apps web**

- **[wabalink](https://wabalink.com)**: WhatsApp Business para todo el equipo en una sola bandeja, sobre la API oficial de Meta.
- **[SIGSA](https://www.desolutec.com/#sigsa)**: contabilidad y gestión societaria para S.A.S. colombianas (libros sobre el PUC, accionistas, asambleas y facturación).
- **[Pharos](https://www.desolutec.com/#pharos)**: panel para administrar servidores Debian desde el navegador, con ingreso por passkeys.

**Apps iOS**

- **[Arqueo Suelos](https://www.desolutec.com/apps/ios/ArqueoSuelos/)**: identificación de suelos y estratos en campo para arqueólogos, sin conexión y sin cuentas.
